# Ailya Shah Portfolio

A small Jekyll portfolio built to feel more like a publication: minimal navigation, a post-first homepage, and space for technical writing.

## Pages

- Home: featured writing and an editorial intro
- About: a compact bio
- Projects: a curated project index
- Contact: social links and profiles

## Run locally

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.

## Deploy to GitHub Pages

1. Push the repo to GitHub.
2. In the repository settings, enable GitHub Pages for the branch you want to publish.
3. If you prefer automated builds, use the GitHub Actions workflow in `.github/workflows/jekyll.yml`.
